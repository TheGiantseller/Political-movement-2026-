# Dicționar de date

Sursa: `content/source/Blueprint_Romania_2026_2030_Victor_v1.json`.

| Câmp sursă | Afișare |
|---|---|
| `portofoliu_reforme[].id`, `sector`, `titlu` | ID-ul, domeniul și titlul din card/fișă |
| `propunere_autor` | Formularea originală etichetată drept propunere |
| `design_implementabil` | Rezumatul măsurii propuse |
| `verificari_legale_necesare` | Verificări juridice încă necesare |
| `temeiuri_si_surse` | Referințe către registrul surselor; articolele S27/S28 sunt ascunse |
| `riscuri_critice`, `masuri_de_garantare` | Riscuri și garanții propuse |
| `indicatori_propuși_fără_baseline_inventat` | Indicatori fără ținte sau baseline afirmate |
| `faza_in_mandat` | Calendar orientativ, etichetat planificat |
| `estime_financiare_de_colectat` | Nu se afișează null ca zero; UI spune Neestimat |
| `schite_proiecte_de_lege[]` | Catalog de schițe, nu acte oficiale |
| `strategie_48_luni.calendar_16_trimestre[]` | Livrabile, criteriu, cost/fonduri; cost null = Neestimat |
| `istorie_constitutionala.inventar[]` | Cronologia actelor; URL doar dacă este prezent în sursă |
| `registru_surse[]` | Titlu, URL, notă și data indicată de consultare; S27/S28 excluse |

Statutul editorial de verificare nu este stocat în blueprint; limitările curente sunt documentate separat.
