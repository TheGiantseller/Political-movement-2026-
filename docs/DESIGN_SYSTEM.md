# Design system

- Fundal crem `#F7F5F0`, suprafață albă, text bleumarin `#10243B`, accent vișiniu `#922D35`, auriu discret `#C6A667`.
- Tipografie: titluri serif și interfață sans-serif cu fallback-uri de sistem. Nu se încarcă fonturi sau imagini externe.
- Container max 1280 px, spațiere pe multipli de 4/8, carduri cu borduri simple.
- Navigație semantică, skip link, focus vizibil, contrast ridicat, adaptare la `prefers-color-scheme` și `prefers-reduced-motion`.
- Culorile și layout-ul se află în `app/globals.css`. Revizuirea manuală de accesibilitate și capturile UI sunt încă necesare.
